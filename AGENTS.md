# Agent Instructions

Before performing any work in this repository, read and follow [the Veritas engineering base prompt](.agents/BASE_PROMPT.md) completely.

Repository-local skills are available under `.agents/skills/`. When a task matches a skill's description, read that skill's `SKILL.md` before acting. The base prompt and the binding documents under `docs/build plan/` take precedence over generic skill advice when they conflict.
